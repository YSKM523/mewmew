# Phase 5b 规格:猫的形象升级 + UI 丰富度

用户反馈:「UI 有点过于简单」「猫的形象需要更贴近布偶猫那种 3D 小猫」。

现在的猫是扁平几何拼的(圆头 + 三角耳 + 圆点眼),本质是个图标而非角色。目标是换成 **Rive 动画角色**,同时提升整体视觉层次、动效反馈、场景感。

## 硬约束:`.riv` 文件必须由外部提供

Rive 动画在 Rive 编辑器(图形界面)里制作,无法由代码生成。因此本 Phase 的工程侧目标是:**把集成、状态机接线、契约做完,美术资源到位即插即用**,在此之前保留现有 SwiftUI 猫作为回退。

获取途径(按成本从低到高):
1. **Rive Community**(rive.app/community)—— 大量免费/CC 授权资源,搜 "cat"。注意核对许可证是否允许商用。
2. **自己用 Rive 编辑器做** —— 网页版免费,有布偶猫参考图的话入门成本不高。
3. **外包** —— Fiverr/Upwork 上找 Rive 动画师定制。

### `.riv` 契约(美术方按此制作,工程侧按此接线)

文件名 `cat.riv`,放 `ios/Mewmew/Assets/`。

| 项 | 名称 | 说明 |
|---|---|---|
| Artboard | `Cat` | 正方形画板,建议 512×512 |
| State Machine | `CatState` | 唯一状态机 |

输入(State Machine Inputs):

| 输入名 | 类型 | 取值 | 含义 |
|---|---|---|---|
| `mood` | Number | 0 / 1 / 2 | 0=精神(睁眼、尾巴摆)1=平静(偶尔眨眼)2=打盹(闭眼、呼吸起伏) |
| `outfit` | Number | 0 / 1 / 2 | 0=无 1=铃铛项圈 2=圆眼镜 |
| `feed` | Trigger | — | 喂食:猫凑过来吃一口,约 1.2s |
| `levelUp` | Trigger | — | 升级:一次明显的开心反应,约 1.5s |

**契约稳定性**:输入名与取值一旦定下不要改——换美术资源时只替换文件,不动代码。

### 回退策略

`RiveCatView` 在 `cat.riv` 缺失或加载失败时,自动回退到现有 `CatView`(SwiftUI 绘制)。**不允许因为缺资源而崩溃或白屏**。设置页显示当前用的是哪一个(参照既有可观测性做法)。

## UI 丰富度(不依赖 .riv,可立即做)

### A. 视觉层次

现在是纯白底 + 橘色按钮的极简风,页面显得空。改动:

- **背景分层**:猫主页给猫舞台一个柔和的底(`Theme.surface` 的圆角大卡片,或极淡的暖色块),让猫"站在某处"而不是浮在白纸上。
- **卡片质感**:今天区的两张卡、记忆列表行,增加轻微的层次区分(描边 + 极淡背景已有,再加 8-12pt 的内边距呼吸感)。
- **间距节奏**:主页各区块之间的留白拉开层次(猫舞台 > 分隔 > 操作区 > 分隔 > 今天区),不要平均分布。
- **仍然:纯色、无渐变、无阴影。** 层次靠色块与间距,不靠光影。

### B. 动效与反馈

现在点按钮、拿鱼干、升级几乎没有动效。加:

- **喂猫**:按钮按下有缩放反馈(0.96);鱼干数字变化用 `.contentTransition(.numericText())`;经验条平滑增长(0.6s easeOut)。
- **升级**:等级徽章一次弹跳(scale 1.0→1.25→1.0,spring),配文案「长大啦」淡入淡出。**触发一次 `levelUp`(Rive 可用时)。**
- **capture 确认**:猫说"记住啦"的气泡从猫身上弹出(scale + opacity),不是硬切。
- **列表**:完成/删除用 `.animation` 平滑移除,不要瞬间消失。
- **触觉反馈**:喂猫、升级、答对卡片用 `UIImpactFeedbackGenerator`(轻度),错误用 notification(.warning)。**克制:只在有意义的正反馈上用。**

### C. 猫窝/场景感

猫现在浮在白底上。给它一个"家":

- 猫舞台底部加一个**垫子**(扁椭圆,`Theme.surface` 或淡暖色),猫坐在上面。
- 垫子两侧可放极简元素:一个小鱼碗(有鱼干时才出现,数量影响碗里的鱼)、`sleepy` 时旁边出现「Zzz」。
- **场景要克制**:不画窗户、不画家具。目标是"猫有个位置",不是画一幅画。层次仍靠纯色块。

## 验收

1. `cat.riv` 不存在时 app 正常运行,猫用 SwiftUI 版本渲染,设置页显示「猫:内置绘制」。
2. 放入符合契约的 `cat.riv` 后,猫切换为 Rive 渲染,三种 mood 与两种装扮正确切换,喂食/升级触发对应动画。设置页显示「猫:Rive」。
3. 喂猫时:按钮有按下反馈、鱼干数字滚动变化、经验条平滑增长、有触觉反馈。
4. 升级时:徽章弹跳 + 文案出现。
5. 猫坐在垫子上;有鱼干时鱼碗出现;打盹时有 Zzz。
6. 快照测试:新的猫主页(三种 mood)、有鱼碗/无鱼碗两态。**动效在快照中禁用**。

## 不做
不引入渐变/阴影;不做复杂场景插画;不做多只猫;Rive 资源本身不由工程侧产出。
