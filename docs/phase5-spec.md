# Phase 5 规格:猫养成

前四个 Phase 做的是功能——能记、能提醒、能召回、能考。Phase 5 做的是**让人愿意回来**。

## 设计立场

养成机制的失败模式不是"不够上瘾",而是**把使用变成负担**。电子宠物类产品最常见的卸载理由是"我对不起我的猫"——用户忘了几天,回来看到一只饿坏的猫,产生愧疚,然后为了不再愧疚而卸载。

所以这里的取舍是:**温和衰减**(用户已确认)。

- 猫会因为几天没互动而"有点蔫",文案是想你了,不是在指责你。
- **等级和鱼干永不倒退**,装扮永不收回。已经获得的成就是不可撤销的。
- 猫**不会离家出走、不会生病、不会死**。最坏情况就是它在窝里睡觉等你。
- 回来一次就能立刻恢复——不需要"补偿性劳动"。

一句话:衰减只影响**当下这一眼看到的样子**,不影响你积累的任何东西。

## A. core:猫状态机

`cat` 表已有 `level / xp / fish / mood / updated_at`。补两列(迁移 v4):
`last_interaction_at INTEGER`、`outfit TEXT`(当前装扮 id,默认 `none`)。

### 鱼干与经验

鱼干已在 Phase 3/4 产出:完成提醒 +1、复习答对 +1。Phase 5 加**消费**:

```rust
fn feed_cat(&self, now: i64) -> Result<CatStatus>;   // 消耗 1 条鱼干,+10 xp
```
- 没有鱼干时返回 `Invalid("没有小鱼干了")`,不报崩溃。
- 每次喂食刷新 `last_interaction_at`。

### 等级

`xp` 累加,等级由 xp 推出,**纯函数、不写死在数据里**(便于将来调曲线):

| 等级 | 累计 xp |
|---|---|
| 1 | 0 |
| 2 | 30 |
| 3 | 80 |
| 4 | 160 |
| 5 | 280 |
| n | 上一级 + 40×(n-1) |

`level` 列作为缓存写回,但**以 xp 为准**——若两者不一致以 xp 重算(防止将来改曲线后数据错位)。

### 心情(温和衰减)

`mood` 是**推导值,不落库为真相**——由 `now - last_interaction_at` 算出:

| 距上次互动 | mood | 猫的样子 |
|---|---|---|
| < 24h | `happy` | 精神 |
| 24–72h | `content` | 平静 |
| > 72h | `sleepy` | 打盹,想你了 |

```rust
fn cat_status_at(&self, now: i64) -> Result<CatStatus>;  // mood 按上表推导
```
保留原 `cat_status()` 作为不含时间的读取(mood 返回落库值),新调用一律走 `cat_status_at`。

**关键:衰减到 `sleepy` 就到底了,没有更差的状态,也不扣任何东西。**

### 装扮

三个,靠等级解锁(不花钱、不看广告——Pro 订阅解锁更多是 Phase 6 的事):

| id | 名称 | 解锁条件 |
|---|---|---|
| `none` | 原样 | 默认 |
| `scarf` | 小围巾 | Lv.2 |
| `glasses` | 圆眼镜 | Lv.4 |

```rust
fn unlocked_outfits(&self) -> Result<Vec<String>>;      // 按当前等级
fn set_outfit(&self, outfit: String, now: i64) -> Result<CatStatus>;  // 未解锁则 Invalid
```

### 测试要求
- 喂食扣 1 鱼、加 10 xp、刷新互动时间;没鱼时 Invalid 且不改任何状态。
- 等级边界:xp=29 是 Lv.1,xp=30 是 Lv.2,xp=79 Lv.2,xp=80 Lv.3。
- mood 三档的边界(23h59m / 24h / 72h / 73h)。
- **衰减不减少 xp/fish/level**(直接断言这三个数在时间推进后不变)。
- 未解锁装扮不能设置;已解锁的可以来回切。

## B. iOS:猫主页升级

猫主页现在是静态图标 + 一行状态。改成:

1. **猫的形象随 mood 和 outfit 变化**。Phase 5 不引入 Rive/Lottie(先不背这个依赖),用 **SwiftUI 绘制 + 简单动画**:
   - `happy`:尾巴轻摆(2s 循环)
   - `content`:静止,偶尔眨眼
   - `sleepy`:闭眼,呼吸起伏(缓慢缩放)
   - 装扮作为叠加图层(围巾/眼镜)
2. **鱼干与喂食**:猫下方显示 `🐟 ×N`;有鱼时出现「喂猫」按钮,点了播放一个短动画(猫凑过来吃)+ xp 增长,升级时有一次明显反馈。
3. **等级与进度**:等级数字 + 到下一级的细进度条(克制,不要游戏化到花哨)。
4. **装扮选择**:猫主页一个小入口,展示三个装扮,未解锁的显示所需等级(灰色但可见——让人知道有东西可追)。

### 文案基调
猫不说教、不催促。`sleepy` 时的文案是「猫在窝里打盹」而不是「你已经 3 天没来了」。差别在于:前者描述猫,后者审判你。

## 验收

1. 完成一条提醒 → 鱼干 +1 → 猫主页出现「喂猫」按钮 → 喂 → xp +10,动画播放。
2. 攒够 30 xp → 升到 Lv.2 → 有明确的升级反馈 → 装扮里「小围巾」变为可选。
3. 把设备时间往后调 4 天(或用注入的时间)→ 猫变 `sleepy`,**但鱼干、xp、等级、装扮一个不少**。
4. 没有鱼干时点喂猫 → 友好提示,不崩溃。
5. 未解锁的装扮点不动,显示"Lv.4 解锁"。

## 不做(留后)
多只猫、猫的名字、社交/炫耀、按天连续打卡(streak)、付费装扮(Phase 6 订阅时再说)、Rive/Lottie 复杂动画。
